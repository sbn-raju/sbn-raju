## 🧑‍💻 About Me

I'm a developer from **Hyderabad, India** who genuinely enjoys the part of an app nobody sees — schemas, queues, async flows and clean APIs. I've shipped production code across internships and freelance work, from healthcare backends to full ERP systems, and I'm now building **AI agents and RAG systems** on top of that backend foundation.

- 🎓 **B.Tech in Computer Science** @ KL University — CGPA **9.35**
- 🔭 Currently: **AI Engineer Intern @ Techsophy**, building AI-generated SOPs for hospitals
- 🌱 Exploring: multi-agent orchestration, RAG pipelines, MCP servers
- 📦 Published: [`snap-bucket`](https://www.npmjs.com/package/snap-bucket) — an npm SDK for direct-to-S3 uploads
- 💬 Ask me about: Node.js, PostgreSQL, message queues, FastAPI, LangChain
